# StrengthPvPHelper

**A customizable PvP utility and HUD mod for Minecraft 1.17.1 Fabric.**

StrengthPvPHelper is a client-side Minecraft modification focused on PvP customization, visual improvements, performance and convenient HUD elements.

### Features

- Customizable HUD with movable and resizable modules.
- Pixel-art Custom Crosshair editor.
- BetterPvP with configurable hand position, rotation and animations.
- FreeLook camera.
- HitRange distance visualization.
- Coordinates, Compass, FPS and Ping displays.
- Keystrokes and Armor HUD.
- Cooldown and Totem notifications.
- Custom Aspect Ratio settings.
- Customizable visual effects and low-fire mode.
- Integrated Crystal Optimizer.
- Configurable interface and custom SynXT bitmap font.
- Performance optimization settings.

### Compatibility

- Minecraft: Java Edition 1.17.1
- Mod Loader: Fabric
- Java: 17
- Environment: Client-side
