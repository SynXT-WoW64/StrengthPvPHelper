StrengthPvPHelper — UI UPDATE — Eclipse / Gradle project
Minecraft 1.17.1 · Fabric Loader 0.14.21 · Java 17 · Author: SynXT

This archive intentionally does NOT contain compiled .class files or a prebuilt JAR.
The new source changes must be compiled with the real Fabric Loom + Sponge Mixin
annotation processor; do not copy .class files from an older archive.

1. Install/select Eclipse Adoptium JDK 17.
2. In Eclipse: File > Import > Gradle > Existing Gradle Project.
3. Select this folder (the one containing settings.gradle).
4. Wait for Buildship to finish syncing.
5. In Gradle Tasks run: clean, then build.
6. For an isolated development client, run Gradle task runClient.
7. The resulting distributable JAR is in build/libs; copy it to your real
   Minecraft instance's mods folder to test with Sodium/Lithium and your modpack.

Do not use old modid_client.launch / modid_server.launch files: those used
hardcoded paths and an obsolete project name; they were removed.

Right Shift = mod menu; F7 = HUD editor; V = FreeLook by default.
HoldHit is completely removed. The pixel font, all-module settings UI, custom
BetterPvP swing controls and Pixel Paint editor are included in the source.
